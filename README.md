# 003 机电设备在线招投标系统 · 前端（Vue 3）

技术栈：**Vue 3 + Vite + Vue Router**，无其他运行时依赖；数据层使用浏览器
localStorage 模拟数据库（含种子数据），前端可完全独立运行演示。

## 快速开始

```bash
npm install
npm run dev        # 开发模式，http://localhost:5180
npm run build      # 生产构建，输出到 dist/
npm run preview    # 本地预览构建产物
```

## 功能与任务书对照

**设备生产厂家**
- 注册与登录（`/register`，角色选「设备生产厂家」）
- 招标信息查询和查看（`/tenders`：关键词、类别、状态筛选 + 分页）
- 在线投标：公告详情「我要投标」，填写投标信息表单（投标日期、投标单位、
  法人姓名、联系电话、招标项目编号、产品生产厂家、生产日期、保质期、
  投标总金额、保证金缴款日期），同一项目限投一次，截止前可撤回
- 在线留言：`/messages` 与控制台「我的留言」，留言经管理员审核后公开

**招标单位**
- 注册与登录（角色选「招标单位」）
- 发布招标信息 / 修改、更新、查询（控制台「招标信息管理」），
  表单字段与任务书一致：项目编号、设备名称、型号、包装要求、数量、
  招标截止日期、投标保证金
- 查看投标情况：控制台「投标情况」，支持按项目筛选、详情查看、导出 CSV
- 查看机电设备生产厂家信息：控制台「厂家信息」

**系统管理员**
- 机电设备厂家的信息管理（查看 / 编辑 / 停用 / 启用 / 删除）
- 招标单位信息管理（同上）
- 留言板维护和管理（审核、答复、取消公开、删除）
- 数据概览与全平台招标信息总览（可下架违规公告）

**数据表单对应**（见 `src/data/seed.js`）
- 机电设备招标信息表单 → `tenders`
- 投标信息表单 → `bids`

## 目录结构

```
src/
├── api/            # 模拟接口层（接后端时只改这里）
│   ├── db.js       # localStorage 读写
│   └── index.js    # auth / tender / bid / message / user / stats 接口
├── data/seed.js    # 种子数据（8 个招标项目、5 条投标、6 条留言、7 个账号）
├── layouts/        # 门户布局 / 控制台布局（按角色渲染菜单）
├── router/         # 路由与角色守卫
├── stores/auth.js  # 登录态（localStorage 持久化）
├── components/     # 弹窗、确认框、Toast、分页、投标表单等通用组件
└── views/
    ├── 首页 / 招标公告 / 详情 / 留言板 / 指南 / 登录 / 注册
    └── console/    # supplier（厂家）/ tenderer（招标单位）/ admin（管理员）
```

## 接入真实后端
所有页面只调用 `src/api/index.js` 中的方法（均返回 Promise）。


## 其他

- 路由使用 hash 模式，`dist/` 可直接静态托管，无需服务端路由配合。
- `verify.mjs` 为开发期页面验证脚本（puppeteer-core 驱动本机 Chrome 截图），
  运行 `node verify.mjs` 前需先启动 dev server，不属于业务代码。
- 重置演示数据：浏览器控制台执行 `localStorage.clear()` 后刷新即可。
